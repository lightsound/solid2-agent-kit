## Accepted residuals (decisions, not oversights)

- The hook's guard is string inspection and has a known ceiling,
  accepted at fix time: a protected path assembled by string
  concatenation inside eval code, backslash-escaped characters inside
  a path beyond separators, or a write performed by a pre-written
  script file (`node /tmp/x.mjs`) are not detected.
- Pipelines are judged as one segment, fail-closed by design: a
  read-only pipeline into an unrelated write verb can be denied; the
  deny message names the workaround. Accepted as the deliberate
  trade-off of the segment rule.
